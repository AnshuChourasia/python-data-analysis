# Python Data Analysis 📊

A beginner-to-intermediate Python data analysis learning repository covering data handling, cleaning, visualization, and exploratory data analysis using popular Python libraries.

This repository contains hands-on practice files created while learning Python for Data Analysis and building a foundation for Data Science.

## 🛠️ Technologies Used

- Python 🐍
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook (for experimentation)

## 📚 Topics Covered

### 1. Pandas Basics
- Creating DataFrames
- Reading and manipulating data
- Selecting rows and columns
- Filtering data
- Basic data exploration

### 2. GroupBy & Aggregation
- Grouping data
- Aggregate functions
- Data summarization
- Working with grouped datasets

### 3. Data Visualization with Matplotlib
- Creating plots
- Line charts
- Bar charts
- Customizing visualizations

### 4. Data Visualization with Seaborn
- Statistical visualizations
- Distribution plots
- Relationship analysis
- Better-looking data charts
